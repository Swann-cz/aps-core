# 1d 年末停线（不带下一年日历）：推算停线长度

规格出处：`spec/CORE_MODEL.md` §5 停线行（“年末尾停长度算到元旦后首个工作日；输入没带下一年日历时，默认 1 月 1 日放假、遇周末顺延”，rev 159）、PS 停前日行。`build.py` 同时生成本目录和 `../1d-year-end-stop-calendar/`。

## 设定

- 计划期 2026-12-14（周一）至 12-31（周四）。12-29 至 12-31 不可生产，周末不可生产。工作日 11 天：12-14 至 18、12-21 至 25、12-28。
- 输入日历只到 12-31。
- 只有车型 A（BS1），胶龄 15。各车间 80 台/天，无授权。
- 目标：**BS1 66**、BS2 130、WBS 35、PS 150、PBS 45、AS_MAIN 100、AS_FIN 80；期初等于目标，成品 0。BS1 取 66 是为了让带日历的那一版清线正好两天（见那边 README），这一版用不到。
- PR：12 月 880。WS：12-28 交 880。

## 判定口径

PS 零流窗口从 12-29 开始，碰到计划期末。按规则推算：2027-01-01 元旦放假，01-02、01-03 是周末，01-04（周一）复工。窗口 12-29 至 01-03 共 **6 天**：≥ 3 是停线，< 15 是短停，停前日 12-28 的 PS 日末必须正好是 **131**。焊装窗口也是 6 天 < 胶龄 15，不清线。

## 手算：为什么最优解唯一

1. L1a = 0 要求 11 个工作日 AS_FIN 每天出 80（共 880）。
2. 期初在目标，L5 = 0 要求不压库存；每个节点每天都在供车，所以每天日末正好等于目标。只有 PS 在停前日 12-28 例外，要正好降到 131。
3. 12-28：PS 出 80，日末 131，所以进 150 + 进 − 80 = 131 → 进 61。WBS 照常 ≥ 35、又不能高于 35，所以 BS1 出 61；BS1 同理进 61。12-28 是 A 当月最后生产日，BS1、PS 少进合法（C14 尾差）。
4. 其余工作日全部 80 / 80。目标全部为 0。

| 日期 | BS1 IN/OUT | PS IN/OUT | AS_MAIN = AS_FIN | PS 日末 | 阶段 |
| --- | --- | --- | --- | --- | --- |
| 12-14 至 12-25 的工作日 | 80 / 80 | 80 / 80 | 80 | 150 | NORMAL |
| 12-28 | 61 / 61 | 61 / 80 | 80 | 131 | PS_PRE_STOP |
| 12-29 至 12-31 | 0 | 0 | 0 | 131 | STOP |

停线清单：`{start 12-29, end 2027-01-03, length 6, pre_stop_date 12-28, target 131, source DEFAULT}`。`end` 写推算出的复工前一天，可以在计划期之后（IO_CONTRACT §3）。

## 反例

- `counter/ps-long-target.plan.json`：12-28 PS 进 21、出 80，日末 91（按长停目标），BS1 进出 21。判定器应 REJECT，违规条款只有 PS_PRE_STOP。
