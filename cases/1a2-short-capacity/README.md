# 1a2 单车型、两周、产能不够

规格出处：`spec/CORE_MODEL.md` C10/C11/C12 的缺产放宽与 §6 L1a/L1b/L1c（2026-10-24 裁决）。本目录由 Claude 维护，`build.py` 重新生成全部文件。

## 设定

与 1a 完全相同（工厂、日历、期初在制 = 目标、成品期初 0、无授权），只改需求：

- PR(A, 2026-03) = 750；产能 8 个工作日 × 80 = 640，做不到。
- WS：03-05 交 400，03-11 交 350。

## 手算：为什么最优解唯一

1. **L1a = 110**：C8 要求各节点 EOD ≥ 目标，期初在制又正好等于目标，所以 FOK 上限就是完成线产能 640。L1a = 750 − 640 = 110，并且要达到这个值，8 个工作日必须天天满产 80，计划因此唯一。
2. **L1b = 190**：按 C11，fin − bl 逐日 = 上一日 + FOK − WS。
   - 03-05：240 + 80 − 400 = −80，欠交 80 台。
   - 03-06：补交后为 0。
   - 03-11：160 + 80 − 350 = −110，欠交 110 台。
   - 欠交台·天合计 80 + 110 = 190；满产已是最早交付，不能更少。
3. **L1c = 35**：月度带下限 750 − 0.1 × 750 = 675，cumFOK 640，差 35。
4. **L2–L5 = 0**：与 1a 相同，各节点 EOD 天天等于目标。
5. **C13**：当月 cumFOK 始终达不到 cumPR，没有任何一天可以空，与满产一致。
