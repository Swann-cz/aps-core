# 1c 标准复线：从标准停线水位复工

规格出处：`spec/CORE_MODEL.md` §5 补线行（期初低于目标从首个生产日补线、逐级补满 B13、补线按满产推进 rev 182）、C14、C17。本算例同时是 T-19 生成器“复线模板”的标准答案。`build.py` 重新生成全部文件。

## 设定

- 计划期 2026-03-23（周一）至 03-27（周五），每天可生产。只有车型 A（BS1）。各车间 80 台/天，无授权。
- 期初 = 标准停线水位（即 `1c-standard-clear` 停线时的日末）：BS1 0、WBS 0、PS 91、PBS 45、AS_MAIN 100、AS_FIN 80；成品 0。
- PR 3 月 236，WS 03-27 交 236。

## 手算：为什么唯一

逐级补满：节点日末未到目标不向下游供车，当天到目标后多出的当天往下流；车间投入按满产，少投只能因上游已到目标（C15 镜像）；没有投入的车间不出车（C17）。

| 日期 | BS1 IN/OUT | PS IN/OUT | AS_MAIN、AS_FIN IN/OUT | 日末 BS1 / WBS / PS / PBS / AS_MAIN / AS_FIN | FOK | 阶段 |
| --- | --- | --- | --- | --- | --- | --- |
| 03-23 | 80 / 10 | 0 / 0 | 0 / 0 | 70 / 10 / 91 / 45 / 100 / 80 | 0 | REFILL |
| 03-24 | 80 / 80 | 55 / 0 | 0 / 0 | 70 / 35 / 146 / 45 / 100 / 80 | 0 | REFILL |
| 03-25 | 80 / 80 | 80 / 76 | 76 / 76 | 70 / 35 / 150 / 45 / 100 / 80 | 76 | REFILL |
| 03-26、03-27 | 80 / 80 | 80 / 80 | 80 / 80 | 同目标 | 80 | NORMAL |

- 03-23：BS1 投 80，补到 70，多的 10 给 WBS；WBS 10 < 35，不供车；PS、总装没有来车，不开（C17）。
- 03-24：WBS 10 + 80 = 90，补到 35，多的 55 给 PS；PS 91 + 55 = 146 < 150，不出车。
- 03-25：PS 146 + 80 = 226，补到 150，多的 76 往下流；PBS、总装都在目标，进多少出多少。
- 目标全为 0；FOK 76 + 80 + 80 = 236 = PR。

## 反例

- `counter/refill-underfeed.plan.json`：首日焊装只投 48、不出车（`C14`）；少出的车让 FOK 不够 PR，同时报 `C11`。
- `counter/lone-output.plan.json`：首日完成线没有来车单独出 3 台（`C17`），日末 77 低于目标还在出车（`REFILL`）。
