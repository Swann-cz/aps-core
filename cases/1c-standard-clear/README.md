# 1c 标准清线：标准摆线进入长停

规格出处：`spec/CORE_MODEL.md` §5 BS 清线行（停线前出清 rev 186、清线零头放在清线前一天 rev 187）、PS 停前日行（停前降库 rev 185）。本算例同时是 T-19 生成器“清线模板”的标准答案：前提满足时，模板套出来的清线段必须与本表一致。`build.py` 重新生成全部文件。

## 设定

- 计划期 2026-03-02（周一）至 03-08（周日）；03-02 至 03-06 可生产，03-07 起停线到 03-22（16 天 ≥ 15，停前目标 91），03-23 复工（计划期后的日历只用于推算停线长度）。
- 只有车型 A（BS1，胶龄 15；焊装零流 03-05 至 03-22 共 18 天 ≥ 15，触发 BS 清线）。各车间 80 台/天，无授权。
- 期初 = 标准摆线（各节点都在目标）：BS1 70、WBS 35、PS 150、PBS 45、AS_MAIN 100、AS_FIN 80；成品 0。
- PR 3 月 400，WS 03-06 交 400。

## 手算：为什么唯一

1. **停线时的水位（rev 186 出清）。** 03-06 日末：BS1、WBS 0，PS 91，PBS 45、AS_MAIN 100、AS_FIN 80。全链从 480 降到 316，清线段要多流出 164 台。
2. **总量。** 5 天 FOK 每天 80 = 400 = PR（总装每天满产）。焊装总投入 = 400 − 164 = 236 = 80 + 80 + 76。
3. **零头位置（rev 187）。** 清线段 PS、总装每天满产，凑不整的 4 台只能放在清线前一天：03-04 焊装投 76、出 80，BS1 降到 66（只此一处不查 C8）。
4. **清线段（03-05、03-06）。** 03-05 BS1 出清 66，WBS 35 + 66 − 80 = 21，PS 进 80 出 80；03-06 PS 进 21、出 80，日末 150 + 21 − 80 = 91。WBS 正好在停前日清空，清线紧贴停线。
5. **目标：** L2 = 1（一次清线），其余为 0。

| 日期 | BS1 IN/OUT | PS IN/OUT | AS_MAIN、AS_FIN IN/OUT | 日末 BS1 / WBS / PS / PBS / AS_MAIN / AS_FIN | 阶段 |
| --- | --- | --- | --- | --- | --- |
| 03-02、03-03 | 80 / 80 | 80 / 80 | 80 / 80 | 70 / 35 / 150 / 45 / 100 / 80 | NORMAL |
| 03-04 | **76** / 80 | 80 / 80 | 80 / 80 | **66** / 35 / 150 / 45 / 100 / 80 | NORMAL（减量投入日） |
| 03-05 | 0 / 66 | 80 / 80 | 80 / 80 | 0 / 21 / 150 / 45 / 100 / 80 | PS_PRE_STOP+BS_CLEAR |
| 03-06 | 0 / 0 | 21 / 80 | 80 / 80 | 0 / 0 / 91 / 45 / 100 / 80 | PS_PRE_STOP+BS_CLEAR |
| 03-07、03-08 | 0 | 0 | 0 | 同上 | STOP |

rev 188 起清线期焊装也能出尽出，03-05 必须一次出完 66（rev 187 时还允许拆成 03-05、03-06 两天出）。算例仍只比目标值、停线清单和阶段（`compare = "none"`），逐日流量由 T-19 模板验收核对。

## 反例

- `counter/tail-after-clear.plan.json`：焊装满产到清线（03-04 投 80），停前日 PS 日末 95 ≠ 91（`PS_PRE_STOP`）。
- `counter/hold-at-stop.plan.json`：清线前一天全线降到 76，停线时 PS 95 未出清（`PS_PRE_STOP`），清线前一天焊装出车没满产（`BS_CLEAR`）；FOK 少 4 台计入 L1a、L1b，不算硬错误。
