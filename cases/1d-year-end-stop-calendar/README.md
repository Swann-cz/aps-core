# 1d 年末停线（带下一年日历）：以日历为准，变成长停

规格出处：`spec/CORE_MODEL.md` §5 停线行（“带了日历以日历为准”，rev 159）、PS 停前日行（长停 91）、BS 清线行。本目录由 `../1d-year-end-stop/build.py` 生成。

## 设定

与 `1d-year-end-stop` 完全相同，只多一处：输入的 `calendar` 多带了 2027-01-01 至 01-13，其中 01-01 至 01-12 不可生产，01-13 可生产（IO_CONTRACT §2：日历可以多带计划期之后的日子）。

## 判定口径

- PS 零流窗口 12-29 至 2027-01-12 共 **15 天** ≥ 15，是长停，停前日 12-28 的 PS 日末必须正好是 **91**。
- 焊装：BS1 的零流窗口至少也是 15 天，不短于胶龄 15，所以要清线。BS1 和 A 的 WBS 必须在停线前清到 0，并且紧贴停线。

## 手算

1. **FOK 上限 880。** L1a = 0 要求 11 个工作日 AS_FIN 每天出 80；下游在目标，所以 PS 每天也出 80。
2. **停前日 PS 只能进 21。** PS 出 80、日末 91，所以 150 + 进 − 80 = 91 → 进 21。12-28 之前 PS 不得下降，每天进 80、出 80，日末 150。
3. **清线只能从 12-25 开始。** BS1 66 + WBS 35 = 101 台，要在清线期内全部进 PS：
   - 只清 12-28 一天：PS 只能进 21，WBS 清不到 0。不行。
   - 从 12-24 开始清：BS1 少投一天（80 台），FOK 达不到 880。不行。
   - 从 12-25 开始清：12-25 PS 进 80，12-28 PS 进 21，共 101，正好。
4. 所以 12-25 BS1 不投入，12-25 与 12-28 两天合计出 66，WBS 在 12-28 日末清到 0。BS1 在两天之间怎么分**不唯一**：12-25 出 45 到 66 都行（12-25 要供 PS 80，WBS 35 + 出 ≥ 80）。所以本算例只比对结论、目标和停线清单，逐日合法性和阶段交给判定器（`expected.engine.compare = "none"`）。
5. **目标：** L2 = 1（一次 BS 清线），其余为 0。

参考计划（`_reference-plan.json`，12-25 BS1 出 66）：

| 日期 | BS1 IN/OUT | PS IN/OUT | AS_MAIN = AS_FIN | BS1 / WBS / PS 日末 | 阶段 |
| --- | --- | --- | --- | --- | --- |
| 12-14 至 12-24 的工作日 | 80 / 80 | 80 / 80 | 80 | 66 / 35 / 150 | NORMAL |
| 12-25 | 0 / 66 | 80 / 80 | 80 | 0 / 21 / 150 | BS_CLEAR |
| 12-28 | 0 / 0 | 21 / 80 | 80 | 0 / 0 / 91 | PS_PRE_STOP+BS_CLEAR |
| 12-29 至 12-31 | 0 | 0 | 0 | 0 / 0 / 91 | STOP |

不管 BS1 怎么分，阶段都一样：12-25 是 BS1 首个 IN = 0、OUT > 0 的日子（OUT 至少 45），12-28 日末 WBS 才清空。

停线清单：`{start 12-29, end 2027-01-12, length 15, pre_stop_date 12-28, target 91, source DEFAULT}`。

## 反例

- `counter/calendar-ignored.plan.json`：不看下一年日历的计划（即 `1d-year-end-stop` 的最优解）。12-28 PS 日末 131 ≠ 91（`PS_PRE_STOP`）；BS1 带 66 台、WBS 带 35 台进了 15 天长停（`BS_CLEAR`）。判定器应 REJECT，违规条款为 BS_CLEAR、PS_PRE_STOP。
