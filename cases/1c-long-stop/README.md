# 1c 单车型、长停（16 天）：BS 清线 + PS 停前日 + 补线

规格出处：`spec/CORE_MODEL.md` §5 BS 清线、PS 停前日、停线、补线、阶段重叠示例（rev 154）。本目录由 Claude 维护，`build.py` 重新生成全部文件。

## 设定

- 计划期 2026-02-02（周一）至 03-06（周五）。假期 02-14 至 03-01（含周末）共 16 天，`is_working_capable=false`。
- 只有车型 A（BS1），胶龄 14。各车间 80 台/天，无授权。
- 目标：**BS1 67**、WBS 37、PS 147、PBS 80、AS_MAIN 100、AS_FIN 40；期初在制等于目标，成品 0。
- PR：2 月 800、3 月 240。WS：02-13 交 800，03-06 交 240。
- 判定口径：PS 零流窗口 02-14 至 03-01 共 16 天 ≥ 15，是长停，停前目标 91；BS1 零流窗口 02-13 至 03-01 共 17 天 ≥ 胶龄 14，要清线；清过线，所以复工后补线。

**为什么 BS1 目标取 67，不取规格示例里的 69：** 取 67 时，BS1 的 67 台加 WBS 的 37 台共 104 台，正好够 PS 两天吃：第一天 80，停前日 24；停前日 PS 进 24、出 80，正好从 147 降到 91，两天 PS 都满产。取 69 时要清 3 天，中间那天 PS 吃不饱，要靠 rev 154 的 C15 镜像扩展才合法，而且那天 PS 进多少车不唯一，不适合做门槛算例（见文末）。

## 手算：为什么最优解唯一

1. **FOK 上限 1040。** BS1 的投入日最多 13 天：清线前 8 天，复工后 5 天。清线日不投入，停线后不投入。最多投 1040 台；期末全链回到目标，所以 FOK 最多 1040 = PR，L1a = 0 要求每个投入日都满投、清线越晚越好。
2. **清线最晚 2 天。** 只清 1 天（02-13）不行：BS1 出 67 后 WBS 有 104 台，PS 最多进 80，WBS 清不到 0；而且停前日 PS 要净降 56，进车不能超过 24。所以清线从 02-12 开始：
   - 02-12：BS1 不投入、出 67，BS1 清空。WBS 37 + 67 − 80 = 24。PS 进 80、出 80，留在 147（停前日之前不得下降）。
   - 02-13：WBS 24 台全部进 PS，WBS 清空，和停线紧贴。PS 出 80，日末 24 + 147 − 80 = 91，正好是长停停前目标。这天同时是 BS 清线日和 PS 停前日。下游照常 80。
3. **停线 02-14 至 03-01：** 全链 IN、OUT 都为 0。库存保留：PS 91，PBS、总装在目标；BS1、WBS 为 0。
4. **补线（逐级补满，未达目标不得向下游供车）：**
   - 03-02：BS1 进 80，要先回到 67，只能出 13。WBS 只有 13，不到 37，不能供 PS。PS、PBS、总装都在目标或以下，也不能供车。FOK 0。
   - 03-03：BS1 进 80、出 80。WBS 13 + 80 = 93，留 37 后可供 PS 56 台。PS 91 + 56 = 147，刚到目标，没有富余可出。FOK 0。当天日末全链都回到目标，补线结束。
   - 03-04 起：恢复满产 80。
5. **目标：** L2 = 1（一次 BS 清线），其余为 0。

| 日期 | BS1 IN/OUT | PS IN/OUT | AS_MAIN = AS_FIN | BS1 / WBS / PS EOD | 阶段 |
| --- | --- | --- | --- | --- | --- |
| 02-02 至 02-11（8 个工作日） | 80 / 80 | 80 / 80 | 80 | 67 / 37 / 147 | NORMAL |
| 02-12 | 0 / 67 | 80 / 80 | 80 | 0 / 24 / 147 | BS_CLEAR |
| 02-13 | 0 / 0 | 24 / 80 | 80 | 0 / 0 / 91 | PS_PRE_STOP+BS_CLEAR |
| 02-14 至 03-01 | 0 | 0 | 0 | 0 / 0 / 91 | STOP |
| 03-02 | 80 / 13 | 0 / 0 | 0 | 67 / 13 / 91 | REFILL |
| 03-03 | 80 / 80 | 56 / 0 | 0 | 67 / 37 / 147 | REFILL |
| 03-04 至 03-06 | 80 / 80 | 80 / 80 | 80 | 67 / 37 / 147 | NORMAL |

FOK：80 × 10 + 80 × 3 = 1040（2 月 800、3 月 240）。停线清单：02-14 至 03-01，16 天，停前日 02-13，目标 91，来源 DEFAULT。

## 反例

- `counter/wbs-not-cleared.plan.json`：02-13 PS 不进车、只出 56，WBS 留 24 台过长假，03-03 才进 PS。WBS 没清空（`BS_CLEAR`）；这 24 台 02-12 焊出、03-03 进 PS，胶龄 19 天 > 14（C7）。判定器应 REJECT，违规条款为 BS_CLEAR、C7。
- `counter/refill-bs-leak.plan.json`：03-02 BS1 进 80 就出 80，日末 0，没回到 67 就向 WBS 供车（`REFILL`）；03-03 再补回。判定器应 REJECT，违规条款只有 REFILL。

## 已裁决（2026-10-24，rev 154）

BS 目标是 69 时（规格 §5 示例），清线要 3 天，中间那天 WBS 只剩二十几台，PS 吃不饱。Swann 裁决：直接上游正在清线，同样算上游供不上，下游不满产合法（C15 镜像）。本算例用 67，不触发这条；判定器自测里要有一份覆盖它。

## 更正（2026-10-24）：逐日流量不唯一

手算第 2 步只证明了“清线从 02-12 开始、02-13 WBS 清空”，没证明 BS1 的 67 台必须在 02-12 一天出完：02-12 PS 要进 80，只要 WBS 37 + BS1 出 ≥ 80，即 BS1 出 43 到 67 都可以，剩下的 02-13 出。表中是其中一种。因此本算例改为只比对结论、目标和停线清单（`expected.engine.compare = "none"`），逐日合法性和阶段交给判定器；阶段在各种分法下都相同。
