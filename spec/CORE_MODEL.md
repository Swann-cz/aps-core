## 0. 用途与范围

本文是排产引擎第一阶段的**唯一必读模型**：用约束规划（CP-SAT）求解年度首次排产。Codex 只读本文和本文点名的条款；`sources/` 下的历史文档不读，除非本文明确引用。

第一阶段只做：Initial 年度排产，车型 A、B，焊装 BS1、BS2，共享 WBS、PS、PBS、总装主线和完成线，支持非零期初在制。

第一阶段不做：Rolling、Actual、Lock、Fix，Session 与版本保存，前端，AI 助手，Portable 打包，性能调优。

本文怎么读：

- 每条约束后括号里是现行规则编号（B 开头见 BUSINESS\_RULES，其他见 2026-10-07 业务契约），只用于追溯，不需要打开原文。
- **【待你决定】** = 需要你拍板的业务选择；**【待核】** = 数据或文档之间不一致，需要核对；没有标记的都是已确认规则。
- 一条规则如果本文和历史文档写法不同，以本文为准；本文有错，改本文，不改代码去迁就历史文档。

## 1. 集合与索引

模型按自然日、车型、节点三个维度展开；节点和流边以输入 Factory 为准（TOP-01）。

| 符号 | 含义 | 说明 |
| --- | --- | --- |
| D | 计划期内每个自然日 d，含首尾 | s 为期首日；周末、节假日也在 D 里 |
| Dᵂ | 日历可生产日 | `is_working_capable = true` |
| Mo | 月份 | 每个 d 属于一个月 mo(d) |
| M | 车型（A、B） | 每个车型绑定一条焊装线 line(m)：A→BS1，B→BS2（TOP-02） |
| L | 焊装线（BS1、BS2） | 共用一个焊装班组 |
| W | 车间：BS1、BS2、PS、AS\_MAIN、AS\_FIN | 车间有当日决策 |
| B | 缓冲区：WBS（焊装→涂装）、PBS（涂装→总装） | 缓冲区没有决策，流量由上下游车间决定 |
| N | 全部在制节点 = W ∪ B | 七个节点；另有成品 FIN |
| K | 工作模式：OFF、SINGLE\_8H、SINGLE\_8P2、DOUBLE\_SHIFT | 每个模式有计划工时 hrs(k) |

流向只有一条链：BS1/BS2 → WBS → PS → PBS → AS\_MAIN → AS\_FIN → 成品。不允许旁路、倒流、报废（FLOW-05）。

## 3. 决策变量

引擎每天只决定三件事：哪条焊装线开工、各车间用什么模式、各车间每个车型进出多少。库存、胶龄、阶段都由这些推出，不得另行“标记”。

| 变量 | 类型 | 含义 |
| --- | --- | --- |
| on(l,d) | 0/1 | 焊装线 l 当日占用班组（有正 IN 或正 OUT） |
| mode(w,d,k) | 0/1 | 车间 w 当日采用模式 k，每日恰好一个 |
| in(w,m,d)、out(w,m,d) | 非负整数 | 车间 w 车型 m 当日投入、产出（台） |
| inv(n,m,d) | 派生整数 | 节点 n 车型 m 日末在制（EOD） |
| fok(m,d) | 派生 | = out(AS\_FIN,m,d)，完成线产出 |
| fin(m,d) | 派生 | 成品日末库存 |
| idle(w,d) | 派生 0/1 | 车间当日全车型 IN=OUT=0 |
| full(w,d) | 派生 0/1 | 车间当日投入等于当日有效产能 |
| phase(d) | 派生枚举 | 当日所处阶段，见 §5 |

缓冲区不设独立变量：WBS 当日 IN = 焊装当日 OUT 合计，WBS 当日 OUT = PS 当日 IN；PBS 同理；AS\_FIN 当日 IN = AS\_MAIN 当日 OUT（TOP-03）。

建模上最难的是阶段是**内生的**：车型何时换线、需求排完后空几天、空闲是否达到 3 天而触发 PS 停前目标，都是计划自己决定的。建议用每日 0/1 指示变量表达阶段，再用蕴含约束开关各阶段的约束；日历已知的假期在建模前就能确定为停线窗口，可以直接固定。

## 4. 硬约束（以正常生产为主线）

C1–C7 任何阶段都成立；C8–C9 只在正常生产日成立；C10–C15 是需求与生产节奏约束。特殊阶段只在 §5 表里放宽或加严，不在这里写例外。

### 物理与产能（任何阶段）

**C1 守恒与不透支**（FLOW-01/02，B04）。每个节点、车型、日期：

```latex
inv(n,m,d) = inv(n,m,d-1) + in(n,m,d) - out(n,m,d), \quad inv(n,m,s-1) = inv_0(n,m), \quad inv(n,m,d) \ge 0
```

inv ≥ 0 已经蕴含“当日 OUT ≤ 日初 + 当日 IN”，所以同日流转合法。

**C2 产能**（CAP-03/04）。每个车间每天一个模式，全车型共用：IN 合计、OUT 合计分别不超过当日能力。能力为预先算好的常数表：

```latex
cap(w,d,k) = \lfloor \min(hrs(k), hrsLim(w,d)) \times \min(jph(w), jphLim(w,d)) \rfloor, \quad \sum_m in(w,m,d) \le \sum_k mode(w,d,k) \cdot cap(w,d,k)
```

**C3 日历与授权**（CAP-01/02，B20）。车间当日可生产 = （日历可生产日，或有周六授权）且没有计划性停线。不可生产日只能是 OFF。默认只允许 SINGLE\_8H，其他模式必须有排产员授权。引擎**不得自行开启**周六或加班；产能不足时只输出建议。

**条件的业务含义**（2026-10-25 裁决；字段格式见 IO_CONTRACT §2.1）。第一阶段只收七种条件：

- **周六授权**：范围内日历不可生产的日子，对所列车间（不列 = 五个车间全部）变为可生产，只放开默认模式；用了计入 L3a。日历本来可生产的日子无效果。
- **模式授权**：范围内所列车间可用指定加班模式；用了计入 L3b。
- **计划性停线**：范围内所列车间（不列 = 全线）只能 OFF，优先于任何授权；形成的零流窗口与日历假期同样按 §5 处理（PS 停前日、清线、补线）。
- **产能损失**：范围内所列车间当日工时 = min(所选模式工时, 工时上限)，产能和 C14 满产都按降低后的工时算。
- **人工目标在制**：范围内 tgt(n,d) = 指定值（C8 下限）；只改目标，不改输入的物理上限 capᴹ（rev 191）；车间没填物理上限时，上限按 C6 跟随当天目标。指定值高于该节点输入的物理上限为输入无效。rev 204（2026-10-29 Swann 裁决）：一条人工目标在制若盖住某次停线窗口内的全部可生产日，它的值就是该节点的**停前水位**——停前日日末该节点精确等于指定值，停线期间在制保持不动。PS：没有人工停前目标时代替 131 / 91（人工停前目标优先）；PBS、总装主线、总装完成线：代替“停线前出清回到目标”的目标值；焊装线和 WBS 仍按 BS 清线规则（长停清到 0）。只盖住停线一部分的人工目标在制不支持，导入预检报错。rev 205 补充：自建空闲与计划停线合并成更长的停线时（例如需求做完提前停线、接上计划停线），整条落在这个停线窗口里的人工目标在制同样是停前水位。例：设备改造停线 2/3–3/31，人工目标在制 PS 30、PBS 50、总装两段 0 → 2/2 日末 PS 30、PBS 50、总装两段 0，降下来的车做成成品。
- **人工停前目标**：指定日子若是 PS 停前日，PS 日末精确等于指定值（可为 0），代替 131 / 91；不是停前日则不生效，在结论里单列“未匹配”（B10）。
- **指定产量**：该车间当天全车型合计 OUT = 指定值（硬约束），车型拆分按 C16 先进先出。

旧版的人工清线、WBS 水位、复线爬坡、禁止模式、少用周六偏好不收。条件格式错误、日期出计划期、节点或模式不存在、同日同节点人工目标冲突，一律 INPUT_INVALID。

**C4 单班焊装**（B05）。on(BS1,d) + on(BS2,d) ≤ 1；任一线当日有正 IN 或正 OUT，就必须 on = 1。启动、清线、补线都不例外。

**C5 车型绑线**（TOP-02）。车型 m 只能在 line(m) 上投入。

**C6 物理上限**（FLOW-04）。每个节点全车型合计 EOD ≤ 物理上限。缓冲区的上限为输入 capᴹ(n)；车间（BS1、BS2、PS、AS_MAIN、AS_FIN）的物理上限 capᴹ(n) 选填（rev 191，2026-10-26 Swann 裁决：上限与目标分开）。填了：上限固定为 capᴹ(n)，人工 WIP 目标条件、PS 停前目标都只改目标，不改上限；正常生产日车间日末可在 tgt(n,d) 与 capᴹ(n) 之间，高于目标的部分按 §6 第 5、6 级计量。没填：上限取该车间当天的目标在制 tgt(n,d)（含人工 WIP 目标条件；PS 停前目标只是当天要降到的水位，不改上限），与 C8 合起来正常生产日车间日末正好等于目标（2026-10-25 裁决的口径不变）；这种随目标的上限只约束本车间水位；日末到目标时，只有该车间自己受限（期初超量正在降、当天自己满产、当天产量被指定）才作为 C15“下游已到物理上限”的依据（rev 202）。期初车间在制高于上限不算输入错误：该车间日末只许减不许增，降到上限以内后按上限执行。

**C7 胶龄 FIFO**（GLUE-01，B17）。每台车的胶龄 = 进 PS 日 − 焊出日 ≤ Lg(m)。按车型先进先出时，可以写成累计量的线性约束：第 d 天为止，必须已进 PS 的车 ≥ 不晚于 d − Lg 焊出的车。期初 WBS 在制按“计划开始前一天焊出”计龄：

```latex
\mathbb{1}[d \ge s-1+Lg(m)] \cdot inv_0(WBS,m) + \sum_{t \le d-Lg(m)} out(BS_{line(m)},m,t) \le \sum_{t \le d} in(PS,m,t)
```

### 正常生产日的在制

**C8 七节点硬下限**（B07、B08）。正常生产日，每个节点 EOD ≥ tgt(n,d)。共享节点按两车型合计；焊装只约束当前在生产的那条线，闲置线保持 0。目标是下限，不是上限，也不要求相等。

**C9 WBS 经验带**（B09）。正常生产日且当天焊装和 PS 都满产时，WBS 合计 EOD ≤ wbsHi。不满产的日子可以越过 wbsHi 和 tgt，越界天数与幅度只报告，不算失败。

### 需求与生产节奏

**C10 年度闭合**（DEM-01，B02）。每个车型全期 FOK 合计 ≤ 全期 PR 合计；不超产、车型间不互抵。欠产只在授权范围内做不到时出现，缺口 = 全期 PR − 全期 FOK，计入 §6 第 1a 级（2026-10-24 裁决）。期初成品不抵减 PR。

**C11 交付时点**（DEM-04）。fin(m,d) − bl(m,d) = fin(m,d−1) − bl(m,d−1) + fok(m,d) − WS(m,d)，fin ≥ 0，bl ≥ 0，两者不同时为正（有车先补交）。bl 是累计欠交，期初为 0；欠交台·天 Σ_d Σ_m bl(m,d) 计入 §6 第 1b 级。产能够时 bl 恒为 0，等价于原来的 fin ≥ 0（2026-10-24 裁决）。

**C12 月度带**（B03）。记 cumPR(m,mo) 为截至该月的累计 PR，cumFOK 同理：

```latex
cumPR(m,mo) - 0.1 \cdot PR(m,mo) \le cumFOK(m,mo) \le cumPR(m,mo) + 0.1 \cdot PR(m,mo+1), \quad cumFOK(m,12) = cumPR(m,12)
```

月度带只是允许偏差，不是目标。授权范围内做不到时只放宽下限：下限缺口 u(m,mo) = max(0, cumPR(m,mo) − 0.1·PR(m,mo) − cumFOK(m,mo))，合计计入 §6 第 1c 级；上限不放宽；末月等式改为 cumFOK(m,12) ≤ cumPR(m,12)，差额即 C10 缺口（2026-10-24 裁决）。

**必须提前量**（rev 204，2026-10-29 Swann 裁决：后面月份做不完的量自动提前到前面月份做）。月度产能估算 Cap(m,mo) = 该月计划期内每个可生产日（日历可生产或有周六授权、且未计划性停线）取 min over {该车型焊装线, PS, AS_MAIN, AS_FIN} 的“当天授权内最高班制产能（含产能损失）”，再按日相加；不扣清线、补线、换型损耗，不扣两车型共用车间的互相占用（估大，提前量偏小，偏保守）。必须提前量 E(m,mo) = max(0, max over 之后各月 j [cumPR(m,j) − cumPR(m,mo) − Σ_{mo<i≤j} Cap(m,i)])。上限改为 cumFOK(m,mo) ≤ cumPR(m,mo) + max(0.1·PR(m,mo+1), E(m,mo))——10% 浮动与必须提前量取大的，不相加。由于 E 已扣掉中间月份的产能，提前量自然先落在紧挨着的前一个月，前一个月做不下才落到更早的月份。为提前生产使用已授权的加班模式视同“PR 做不完时加班”。提前不另设目标级，计划说明里写明哪个月因哪个月做不完提前了多少台。判定器和生成器用同一算法计算 E。例：改造停线例 2 月只有 2/2 一个工作日（授权 11 小时，110 台），3 月全月停线，2 月 PR 424 → E(1 月) = 424 − 110 = 314，1 月上限 908 + 314 = 1222。

**C13 空闲许可**（B03、U-01）。可生产日空闲必须有原因。“需求已排完”只在该车型截至前一日（日初）的完成线 cumFOK 已达到当月 cumPR 时成立，对焊装、PS、总装所有车间统一适用；上游车间不能因自己的累计流量已够而比完成线提前空（2026-10-24 裁决）。此外只能在一整段连续生产结束后空，不能在段中间空；“段中间”按同月判，即空闲后同月内该车间不得再生产，下月开工不算（2026-10-24 确认）。其他合法原因：另一条焊装线占用班组、停线条件、清线后保持、补线中。授权周六不用不算空闲（2026-10-26，随 T-23 缺口建议方案 B）：日历不可生产、只由周六授权放开的日子，车间 OFF 在所有规则里都视同日历休息日（不查 C13，不打断“同月连续生产段”，停线窗口按休息日计）；按车间分别生效，同一授权日可以部分车间上班、部分不上。

**C14 满负荷生产段**（U-02、B18、B19）。生产段由真实的清线、停线、补线、启动切分，月界和普通周末不切分。这里的“停线”包括不触发 BS 清线的 PS 短停：PS 停前日是一个生产段的段末，复工后首个生产日开新段，尾差日资格重新计（rev 198，2026-10-27 Swann 确认，与判定器现行做法一致）。注意与 L2 计数的“焊装段”区分：短停不切焊装段、不增加换型清线次数，只切 C14 生产段。段内每个生产日按当日选定模式满产；每条焊装线/车型每段最多一个尾差日，且在段末。另外允许不满的位置：该车型当月最后生产日、换型后新车型首日、下游节点（缓冲或车间）已到物理上限、§5 中的清线/退出日。补线、首次启动、换型补满期间也按满产投入，少投只能来自 C15 的两种受限或上述其余豁免（2026-10-26 裁决：复线按满产推进；例如复线首日焊装投 80、日末补到目标后多出的 10 台当天给 WBS，不能只投 48 不出车）。满产以选定的合法模式为准，不要求用最高授权模式。满产按当天能力 cap(w,d,k) 算：产能损失日做满降低后的能力也算满产（rev 198，2026-10-27 Swann 确认）；清线期“能做尽做”的“不满”只指上游供不上造成的少产（rev 197）。

**C15 下游受限时上游自然减产**（S19 F6）。不单独定义“PS 受限”。PS 出不了车时 WBS 会堆到物理上限（C6），焊装自然只能少产；总装受限时 PBS 同理传到 PS。判定口径：当天直接下游节点（缓冲或车间，2026-10-25 起含车间）EOD 已到物理上限，上游车间不满产合法，不计 C14 尾差，也不查 C9（10-24 确认）。下游是车间时，该车间填了物理上限按上限判；没填上限的车间平时日末就等于目标，日末到目标时还须它自己受限才算到上限：期初超量正在降回目标（日初或日末高于目标）、当天自己已满产（产能损失日按降低后的能力）、或当天产量由排产条件指定；只是跟着上游停在目标、自己也少产的不算（rev 202，2026-10-28 Swann 裁决：否则完成线天天“满”，总装主线可以随意少产、攒车留到清线时满产）。镜像情形——上游供不上时下游自然减产：当天某车间的直接上游节点（缓冲或车间）EOD 已等于 tgt，该车间不满产合法，不计 C14 尾差（2026-10-24 裁决；例如 BS2 只有 8 JPH 时 PS、总装随之减产）。直接上游节点当天处于 BS 清线期（正在清空）时，同样算上游供不上，下游不满产合法（2026-10-24 裁决）。

**C16 顺接换型与跨车型先进先出**（SEQ-01，2026-10-25 裁决）。每个节点里的车不分车型排成一队，先进先出。车型只在焊装换型时切换：旧焊装线停焊后，新车型紧跟在旧车型后面上线。旧车型 = 换型前焊装在产的车型，新车型 = 换型后的车型。按数量写：换型后，任一节点当天有新车型出车，则该节点旧车型当天日末在制必须为 0（同一天可以先出完旧车型、再出新车型）；上游同样先出旧车型，所以旧车型清空后不会再进入该节点。期初：全链期初在制都排在计划期内焊出的车前面，期初在制之间（含不同车型）不查先后。按数量写：记 I(n,m) 为节点 n 及其全部上游节点里车型 m 的期初在制；节点 n 车型 m 的累计出车一旦超过 I(n,m)（即计划期内焊出的 m 开始出该节点），其他车型 m′ 在该节点的累计出车必须已 ≥ I(n,m′)。期初双线排空不是本条意义上的换型：排空线上的车都是期初在制，先后只按上面的期初口径判（2026-10-25 裁决）。不允许旧车型的车停在节点里给新车型让路或用来凑 C8 目标；旧车型按 C14 满产段连续流出，只有停线、下游已到物理上限（C15）等合法原因可以停。C7 胶龄检查不变。

**C17 无投入不出车**（2026-10-26 裁决）。车间当天 IN = 0 时 OUT 必须 = 0：开一个车间就要排整个车间的人，不为消化几台超目标的在制单独开线出零星车；停线前多出的在制留到恢复流动后自然消化（超出物理上限的在制按 C6 只减不增）。例外只有主动清空的阶段：BS 清线、换型旧线清线、期初双线排空的排空线、PS 停前日的 PS、车型退出。例：复线首日总装完成线还没有来车，不能为把 83 降到 80 单独出 3 台。

## 5. 阶段状态机

历史上十几条“例外裁决”，归纳起来只是一个状态机：每天处于一个阶段，每个阶段只是对 §4 的 C8/C9/C13/C14 做放宽，并新增少数几条约束。C1–C7（守恒、产能、授权、单班、上限、胶龄）在所有阶段都不放宽。阶段只能从输入和逐日流量推出，生成器的标签不算数（B21）。

**R6 / R10（B14）已取消**。2026-10-24 裁决：补线只在清过线的长停之后触发，任何节点都必须先补满才向下游供车，不再设 R6（停前 PS 已空）、R10（PS 能力有余量）的豁免。取消理由：R6 在默认停前目标下触发不了；R10 只在产能富余时生效，省下的产量意义不大，却会让补线可以无限期拖下去。

### 阶段重叠示例（rev 195，2026-10-27 按 2026-10-26 裁决重算；取代 2026-10-24 的旧示例）

长假前，BS 清线和 PS 停前日会落在同一天。有 BS 清线的停线，PS 从首个 BS 清线日起进入停前降库（见上表“PS 停前日”行），不再要求停前日之前保持 tgt。

设定（假设数据）：只有车型 A，胶龄 14 天；假期 02-14 至 03-01 共 16 天，对 BS1 是长停（≥14，要清线），对 PS 是长停（≥15，停前目标 91）。02-13（周五）是最后工作日。各车间 80 台/天；02-10 日末 BS1 69、WBS 37、PS 147，下游各节点在目标。

要做到：02-13 日末 BS1、WBS = 0，PS = 91，PBS、总装在 tgt；清线段 PS 和总装每天满产出车。清线期要流出 BS1 + WBS + (PS − 91) = 69 + 37 + 56 = 162 台，PS 每天 80 台，满产 2 天是 160 台，零头 2 台放在清线前一天消化：

| 日期 | BS1 IN / OUT | BS1 EOD | WBS EOD | PS IN / OUT | PS EOD | 当日阶段 |
| --- | --- | --- | --- | --- | --- | --- |
| 02-11 | 78 / 80 | 67 | 37 | 80 / 80 | 147 | 正常（清线前一天减量投入，BS1 只此一处可低于 tgt） |
| 02-12 | 0 / 67 | 0 | 24 | 80 / 80 | 147 | BS 清线 + PS 降库 |
| 02-13 | 0 / 0 | 0 | 0 | 24 / 80 | 91 | BS 清线 + PS 降库 + PS 停前日 |

PS 降库按公式逐日计算：投入 = min(80, WBS 日初 + 当日焊装出车)，出车 = min(80, PS 日初 + 投入 − 91)。02-12 投入 min(80, 37 + 67) = 80、出车 min(80, 136) = 80；02-13 投入 min(80, 24) = 24、出车 min(80, 80) = 80。PS 两天都满产出车，02-13 PS 投入不满属于清线期。本例 02-12 PS 日末恰好仍是 147，是数据凑巧，不是要求。

合并规则（2026-10-24 确认，rev 195 按 2026-10-26 裁决修订第 2 条）：

1. 按节点、按日豁免：哪个阶段把哪个节点、哪一天排除在正常生产之外，只免该节点该日的 C8、C9、C14；BS 清线不自动豁免 PS，但有 BS 清线的停线中，PS 降库期由“PS 停前日”行的降库规则单独规定。
2. 各阶段新增的约束**全部同时成立**，不互相抵消。例如清线期内，PS 降库公式、停前日 PS 精确等于停前目标、PBS 和总装在停前日为 tgt，要同时满足。
3. 同时成立不可行时，只能按 CLR-05 把清线期向前延长；仍不可行，就报告“未找到满足条件的计划”并请示，不宣称整个问题不可行，也不自行放宽。前移后的清线期仍须满足零投入、清空后不重启、紧贴停线。

## 6. 目标函数

建议采用**分级目标**（lexicographic）：先把第 1 级做到最好，固定住，再在此前提下优化第 2 级，依此类推。这样不需要任何权重，与契约 PREF-05“未经裁定不设权重”不冲突，只需要你定下**顺序**。

为什么必须定：现在的 V2 引擎默认不设目标，求解器只会返回“某一个”合法计划，哪一个由搜索顺序和引导参数决定。计划好坏没有定义，就只能靠不断补规则、补测试去排除“看起来不对”的解。

顺序已于 2026-10-24 确认，按下表执行：

| 级别 | 最小化什么 | 理由 | 依据 |
| --- | --- | --- | --- |
| 1 | PR 缺口，分三个子级依次优化：1a 全期 PR 缺口（台）→ 1b 欠交台·天 → 1c 月度带下限缺口合计（台）；只在授权范围内做不到时才非零（2026-10-24 裁决） | 做不到时仍返回一份“缺得最少”的计划和缺口说明，而不是只返回 UNKNOWN | B03、B21 |
| 2 | 换型与清线次数 | 成块生产是业务实情，频繁交替本来就排不出（S19 F2/F3） | S19 |
| 3 | 非默认模式与周六的使用量 | “选满足需要的最低模式”是既有偏好；先平日加班、后周六（已确认） | PREF-02、B20 |
| 4 | WBS 越出经验带的天数 | 生产平顺，对应用户“尽量大部分时间保持在这个值” | B09 |
| 5 | 各节点高于目标的在制总量 | 少压库存，减少胶龄风险。第 6 级（最低，2026-10-26 裁决）：同样多的超目标在制，尽量停在下游——出不去的车就顺着线往下流，不留在上游缓存；度量 = Σ日 Σ节点 max(0, EOD − tgt) × 节点权重，权重 AS_FIN 1、AS_MAIN 2、PBS 3、PS 4、WBS 5、BS1/BS2 6 | 新提议 |

需要你决定：

- [ ] 上表顺序是否采用？特别是第 2 级和第 3 级谁在前：“宁可多开周六也少换型”，还是“宁可多换型也少开周六”。
- [ ] 第 3 级里周六和平日加班怎么比：已定，先用平日加班，不够再用周六（2026-10-24 确认）。
- [ ] 第 5 级是否需要，或者换成你心里的其他标准（例如成品库存少、各月产量均衡）。暂时不需要更改，按你建议来。

实现方式：每级单独求解一次，把上一级的最优值作为约束加入下一级；一级超时未证最优，就用当前最好值继续，并在结果里注明哪级未证最优。

生成器找解方法（2026-10-24 裁决）：先月度粗排、再逐日细排。每月每车型的产量边界由输入直接算出（上限按 C11 月度带，硬；下限按月度带，低于计入 1c），粗排据此定每月计划量、焊装天数和车型顺序，逐日细排以它为骨架。当月需求做完、完成线本月不能再出车时，整线停到下月，不再投入只能堆在车间里的车；连停达到停线天数时按 §5 自建停线处理（PS 停前日降水位、复工走补线）。这是找解方法，不是新增硬约束，判定器不另查；多压的在制仍由第 5 级计量。

## 7. 输入、输出与结论

输入沿用现有 `PlanningRequest` 结构：计划期、日历、Factory（车间、缓冲、模式、车型与胶龄、流边）、月度 PR/WS、可选逐日 WS、期初快照、基础 WIP 目标、条件列表（停线、产能损失、周六与模式授权、人工 WIP 目标、停前目标、指定产量）、规则常数配置。字段名以 2026-10-07 输入输出契约为准。

输出三部分：

1. 逐日计划：每个自然日一行，每个车间的模式、工时、按车型 IN/OUT，每个节点按车型 BOD/EOD，FOK 与成品库存，并标出当日阶段及其依据。
2. 停线清单：每次 ≥3 天 PS 停线的起止日、长度、采用的停前目标及来源（DEFAULT 或 MANUAL+条件号）；未匹配的人工停前目标单列（B10）。
3. 结论与说明：PR 缺口、WS 交付、违规、输入冲突、求解未完成分开列；产能不足时给出可开周六/加班的建议（B20、B21）。

| 结论 | 成立条件 |
| --- | --- |
| FEASIBLE | 生成器给出计划，**且**独立判定器零硬错误 |
| PROVEN\_INFEASIBLE | 有只依赖输入、可手工复查的矛盾证明；求解器报 INFEASIBLE 本身不算 |
| UNKNOWN | 超时或受限模型无解，但无证明；附卡住的月份和约束 |
| INPUT\_INVALID | 预检失败（同日同节点目标冲突、负值、超物理上限、目标在制或人工目标高于该节点输入的物理上限等），不生成计划 |
| EXECUTION\_ERROR | 程序异常，或生成器的计划被判定器否决 |

判定器必须独立于生成器：不导入生成器代码，只从原始输入和逐日流量重算阶段和全部约束。这是现有资产里最值得保留的部分。

## 8. 分阶段交付与验收算例

每一步的门槛都是两件事：独立判定器零硬错误；你看了计划说“对，就是这个意思”。上一步没过，不开始下一步；每一步只加对应的约束和测试，不提前写后面阶段的边界测试。

1. **1a 单车型、两周、只有正常生产**：C1–C14 中与单车型有关的部分，目标函数。用下方算例验收。
2. **1b 两车型、一个月、一次换型**：单班 C4、换型阶段、闲置线保持 0。
3. **1c 加入日历假期**：PS 停前日、停线、BS 清线、补线。
4. **1d 全年**：期初在制（期初补线）、期初双线排空、首次启动、多次换型、月度带、计划期首尾停线；用 9-15 业务反馈输入跑通。车型退出等输入带停产标记后再做（2026-10-24 裁决）。
5. **第二阶段**：Rolling、Actual、Lock、Fix，另写模型文档。

### 1a 验收算例

设定：计划期 2026-03-02（周一）至 03-11（周三），共 10 个自然日、其中 8 个工作日，03-07/08 为周末。只有车型 A（BS1），各车间 10 JPH × 8 小时 = 80 台/天，无授权周六和加班。期初在制正好等于目标：BS1 69、WBS 37、PS 147、PBS 80、AS\_MAIN 100、AS\_FIN 40，期初成品 0。PR = 600，WS = 600 全部落在 03-11。A 胶龄 14 天。

预期唯一的最优计划：

| 日期 | 每个车间 IN = OUT | 各节点 EOD | 当日阶段 |
| --- | --- | --- | --- |
| 03-02 至 03-06 | 80 | 保持在目标 | 正常 |
| 03-07 至 03-08 | 0 | 保持在目标 | 周末，2 天不构成 PS 停线，也不切断生产段 |
| 03-09 至 03-10 | 80 | 保持在目标 | 正常 |
| 03-11 | 40 | 保持在目标 | 正常，段末尾差日 |

核对点：FOK 合计 7 × 80 + 40 = 600 = PR；03-11 成品 600 − 600 = 0，不缺货；停线清单为空；期初 WBS 37 台于 03-02 进 PS，胶龄全部合格；结论 FEASIBLE。

这个算例也说明了为什么需要目标函数：“焊装 8 天全部满产 640 台、完成线只出 600 台、多出的 40 台留在线上”同样满足全部硬约束（目标只是下限）。只有第 5 级目标（少压在制）才会把它排除。
